Model Overview

Our prediction model combines three complementary approaches to generate accurate game and series predictions.

Elo Rating System

Each team has a dynamic Elo rating that updates based on game results. The Elo difference is converted to win probability using the logistic function.

Formula:
P(win) = 1 / (1 + 10(-elo_diff / 400))
Home court adds ~100 Elo points (~3-4% win probability boost)
Playoff bonus: +50 Elo points for series advancement

Team Statistics Model

A composite strength score is calculated from multiple team statistics, each weighted by predictive power.

OffRtg / DefRtg / NetRtg
FG% / 3P% / FT%
Pace / Rebound% / AST Ratio
eFG% / True Shooting%

Monte Carlo Simulation

10,000 simulations of the remaining series, each using per-game probabilities. This gives us the full distribution of possible outcomes.

Accounts for series dynamics:
Desperation factor (elimination games)
Momentum (win/loss streaks)
Close-out pressure
